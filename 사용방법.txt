===============================================================
           크레인 양중분석 프로그램 - 사용 방법
===============================================================

📥 다운로드한 파일을 압축 해제한 후 사용하세요.

┌─────────────────────────────────────────────────────────┐
│                   🪟 Windows 사용자                      │
└─────────────────────────────────────────────────────────┘

1. "크레인분석_실행.bat" 파일을 더블클릭
2. 프로그램이 자동으로 실행됩니다!

※ Python이 설치되어 있지 않다면:
  - https://www.python.org/downloads/ 접속
  - "Download Python" 클릭 후 설치
  - 설치 시 "Add Python to PATH" 꼭 체크!


┌─────────────────────────────────────────────────────────┐
│                    🍎 Mac 사용자                         │
└─────────────────────────────────────────────────────────┘

1. "크레인분석_실행.command" 파일을 더블클릭
2. 프로그램이 자동으로 실행됩니다!

※ 처음 실행 시 권한 오류가 나면:
  - 파일 우클릭 → "열기" 선택
  - 또는 터미널에서: chmod +x 크레인분석_실행.command


┌─────────────────────────────────────────────────────────┐
│                   🐧 Linux 사용자                        │
└─────────────────────────────────────────────────────────┘

1. "run_all_examples.sh" 파일을 더블클릭
2. 또는 터미널에서:
   chmod +x run_all_examples.sh
   ./run_all_examples.sh

===============================================================
                    💡 프로그램 기능
===============================================================

• 크레인 용량 및 작업 반경 계산
• 양중물 하중 분석
• 안전율 자동 검토 (안전/위험 판정)
• 상세 분석 리포트 생성
• 이동식 크레인, 타워 크레인 지원


===============================================================
                     ❓ 문제 해결
===============================================================

Q. 프로그램이 실행되지 않아요
A. Python이 설치되어 있는지 확인하세요
   터미널/명령 프롬프트에서: python --version

Q. "python을 찾을 수 없습니다" 오류
A. Python 설치 후 컴퓨터를 재시작하세요

Q. 한글이 깨져요
A. 터미널/명령 프롬프트의 인코딩을 UTF-8로 설정하세요
